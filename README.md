# IdleHub — downloads

Aqui ficam os instaladores do **IdleHub**, o navegador multi-contas para jogos idle.

## Como instalar
1. Abra a página de **[Releases](../../releases/latest)**.
2. Baixe o **`IdleHub-Setup-x.y.z.exe`** (instalador) ou o **`IdleHub-x.y.z.exe`** (portátil, abre sem instalar).
3. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo** (o app não tem assinatura digital paga).

Depois de instalado, o IdleHub **se atualiza sozinho** quando sai uma versão nova.

## Não aparece "Atualizações do IdleHub" em Configurações → Sobre?
Sua cópia é antiga, de antes da atualização automática existir (por exemplo, uma pasta
copiada de outra pessoa). Ela nunca vai se atualizar sozinha. Para resolver, **uma vez só**:
1. Feche o IdleHub (inclusive o ícone perto do relógio → Sair).
2. Baixe e execute o **`IdleHub-Setup-x.y.z.exe`** mais recente da página de **[Releases](../../releases/latest)**.
3. Pode apagar a pasta antiga depois. Contas, logins e configurações **não se perdem**:
   ficam guardados em `%APPDATA%\IdleHub`, separados do programa.

A partir daí as versões novas chegam sozinhas.

> O **portátil** (`IdleHub-x.y.z.exe`) não se instala sozinho: ele só avisa que há versão nova.
> Para receber as atualizações automáticas, use o **instalador** (`Setup`).

> Este repositório só guarda os instaladores; as versões são publicadas automaticamente.
